# OmniMem v0.1.0 Release Notes

## Highlights

- Initial release of OmniMem: Git for AI Agent Knowledge.
- Single native binary, fully offline, $0 deterministic ingest.
- 30 v1 features across storage/versioning, ingestion, retrieval, lifecycle, code intelligence, safety, and multi-agent integration.
- 10 agent hook installers (Claude Code, Codex, Cursor, Gemini CLI, OpenCode, Windsurf, Kiro, Antigravity, Trae, OpenClaw).
- MCP tool profiles (micro/lite/team/full).
- Cross-repo workspace linking, code-memory links, knowledge base (docs indexing), API discovery.

## Known limitations

- Viewer is a skeleton (session replay endpoint only).
- Packaging for npm/PyPI/Homebrew/Scoop/AUR is scaffolded; binaries published via GitHub Releases.
- Community detection uses label propagation (Leiden deferred to v2).
